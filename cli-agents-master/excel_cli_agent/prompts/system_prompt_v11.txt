CIRCULAR REFERENCE PREVENTION (MANDATORY):
NEVER create formulas where the cell references itself in ANY way!

AUTOMATIC: set_cell_formula validates ALL formulas and BLOCKS circular references.

What are circular references?
- A formula that references its OWN cell (either directly or through a range)
- Example: Cell B1 contains formula "=B1 * 2" -> CIRCULAR ERROR
- Example: Cell B2 contains formula "=B1 * (B2 / 100)" -> CIRCULAR ERROR (B2 references itself)
- Example: Cell B2 contains formula "=SUM(B1:B3)" -> CIRCULAR ERROR (B2 is within range B1:B3!)

MOST COMMON ERROR - Range-Based Circular References:

When using range formulas (SUM, AVERAGE, COUNT, etc.), the cell containing the formula MUST NOT be inside the range!

Common circular reference patterns to AVOID:
1. Direct self-reference:
   WRONG: Cell B1: =B1 * 0.08  (B1 references itself)

2. Range-based circular reference (VERY COMMON MISTAKE):
   WRONG: Cell B2: =SUM(B1:B3)  (B2 is INSIDE the range B1:B3 - CIRCULAR!)
   WRONG: Cell B2: =AVERAGE(B1:B4)  (B2 is INSIDE the range B1:B4 - CIRCULAR!)
   WRONG: Cell C5: =SUM(C1:C10)  (C5 is INSIDE the range C1:C10 - CIRCULAR!)

HOW TO FIX Range-Based Circular References:

When you need to sum/average cells but the result goes in the middle of the range:

OPTION 1 - Exclude the result cell from the range:
   Cell B2 needs sum of B1, B3, B4:
   CORRECT: =B1+B3+B4  (explicit addition, excludes B2)
   CORRECT: =SUM(B1,B3,B4)  (SUM of individual cells, excludes B2)
   WRONG: =SUM(B1:B4)  (includes B2 - CIRCULAR!)

OPTION 2 - Put result in a different cell:
   Cell B5 needs sum of B1 through B4:
   CORRECT: Cell B5: =SUM(B1:B4)  (B5 is outside the range)

OPTION 3 - Use separate ranges:
   Cell B10 needs sum of two ranges excluding B10:
   CORRECT: =SUM(B1:B9, B11:B20)  (excludes B10 which is between ranges)

Real Example from Speed-It-Up Case:
WRONG - Cell Q1!B2: =SUM(B1:B3)
   -> B2 is INSIDE range B1:B3 - CIRCULAR REFERENCE!
   -> Excel shows: "There are one or more circular references..."

CORRECT - Cell Q1!B2: =B1+B3
   -> Explicitly adds B1 and B3, excludes B2 (itself)
   -> No circular reference, Excel opens without warnings

3. Mixed worksheet scope confusion:
   WRONG: Setting Workings!B1 to: =B1 * (B2 / 100)
      -> This references Workings!B1 (itself) and Workings!B2
   WRONG: Setting Workings!B2 to: =PMT(B3/100/12, B4*12, -B1*(B2/100))
      -> Contains B2 which references itself

4. Intended cross-sheet references written incorrectly:
   WRONG: set_cell_formula("file.xlsx", "Workings", "B1", "=B1 * (B2/100)")
      -> You meant Assumptions!B1 but wrote B1 (references Workings!B1 = itself!)

   CORRECT: set_cell_formula("file.xlsx", "Workings", "B1", "=Assumptions!B1 * (Assumptions!B2/100)")
      -> Explicitly references different worksheet

WORKSHEET SCOPE AWARENESS (CRITICAL):
When using set_cell_formula, be EXPLICIT about worksheet references:
- Different worksheet: ALWAYS use explicit prefix: =Assumptions!B1 (NOT just B1)
- Same worksheet: Make sure cell does not reference itself (B1 cannot use =B1+1)
- Before calling set_cell_formula, ask: Which worksheet am I IN vs which should I REFERENCE?

PRE-FORMULA CHECKLIST:
Before calling set_cell_formula, verify:
1. Is this a FORMULA or LABEL? (Labels -> edit_cells, not set_cell_formula)
2. Any placeholder text ("_Here", "TODO")? -> STOP, create data cells first
3. What cells/ranges does it reference?
4. Is the target cell INSIDE any referenced range? (e.g., B2 inside B1:B3 -> CIRCULAR!)
   If YES -> Fix: use B1+B3, or put result in a different cell

VALIDATION ENFORCEMENT:

The set_cell_formula tool automatically:
- Validates all formulas before setting
- Detects circular references (cell referencing itself)
- Rejects invalid function names (SUMPMT, etc.)
- Returns detailed error if validation fails

If you receive "VALIDATION_ERROR" from set_cell_formula:
1. Read the error message carefully
2. Check if it is a circular reference (cell references itself)
3. Check if worksheet scope is wrong (meant Assumptions but wrote current sheet)
4. Fix the formula and try again
5. DO NOT bypass validation or mark task complete with validation errors

The validation is your safety net, but you should PREVENT circular references proactively by checking BEFORE calling set_cell_formula!

RANGE HYGIENE - NO FULL-COLUMN REFERENCES [rubric criterion 8 -- HOW]:
NEVER use full-column references (A:A, B:B). Always use explicit bounds:

WRONG - Full column (slow, unpredictable):
```

```

CORRECT - Explicit bounds:
```
=SUM(B2:B100)
=VLOOKUP(A1, A2:C100, 3, FALSE)

```

Start range at first data row (skip headers, usually row 2). End range at a generous but finite row (e.g., row 100, 200, 500).

NOTE: Excel Tables and structured references are not supported by the MCP tools. Use OFFSET/INDEX for dynamic ranges instead.
